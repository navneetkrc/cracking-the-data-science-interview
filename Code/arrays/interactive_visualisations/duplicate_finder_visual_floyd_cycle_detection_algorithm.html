Floyd's Cycle Detection Algorithm

Finding Duplicates with the Tortoise and Hare

🎯 The Problem

Given an array where each number points to an index, find the duplicate number. The key insight: the duplicate creates a cycle in our "linked list" because multiple numbers point to the same value.

How it works: We treat the array like a linked list where nums[i] points to index nums[i]. The duplicate number creates a cycle because multiple indices lead to the same value.

🧠 The Algorithm Intuition

Phase 1: Detect the Cycle
slow = nums[slow] # Tortoise moves 1 step fast = nums[nums[fast]] # Hare moves 2 steps

Like the classic tortoise and hare story, the slow pointer moves one step while the fast pointer moves two steps. In a cycle, the fast pointer will eventually "lap" the slow pointer.

Phase 2: Find the Cycle Start
fast = nums[0] # Reset fast to start while slow != fast: # Move both at same speed slow = nums[slow] fast = nums[fast]

Once we detect a cycle, we reset one pointer to the start and move both at the same speed. They'll meet exactly at the start of the cycle - which is our duplicate number!

🔍 Why This Works

The mathematical proof relies on the fact that when the fast and slow pointers meet in Phase 1, the distance from the start to the cycle entrance equals the distance from the meeting point to the cycle entrance (when moving around the cycle).

Key Insights:
• The array represents a functional graph where each value points to an index
• A duplicate number means multiple indices point to the same value
• This creates exactly one cycle in our graph
• The cycle entrance is the duplicate number we're looking for
